Introduction to LLM-based Code Agents

Large language model (LLM) based code agents extend basic code generation models into autonomous interactive systems. Beyond producing static code snippets, these agents adopt closed-loop pipelines: they formulate reasoning, generate code, execute it in isolated sandboxes, observe outputs, and iteratively revise programs to fulfill given tasks. Such agents leverage external tools to handle complex programming requirements, including file operations, data parsing, and lightweight local computation. All demonstrations run inside restricted, non-privileged sandbox environments.
